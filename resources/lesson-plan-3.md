# Lesson Plan 3 — Stakeholders

## Focus
Students analyse how different groups influence redevelopment decisions in a place such as Honeysuckle.

## Learning intentions
- identify stakeholder interests
- explain competing values in planning decisions
- evaluate trade-offs and compromises

## Key activities
- stakeholder planning task
- redevelopment negotiation
- decision matrix

## Evidence of learning
- group negotiation notes
- decision matrix completion
- exit ticket response
